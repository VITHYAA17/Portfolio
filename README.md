## 🚀 Running Locally

To host and view this website on your local machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/VITHYAA17/Portfolio.git
   cd Portfolio
   ```
2. **Run a local server** (Handles assets, paths, and script loaders properly):
   * Using Python:
     ```bash
     python -m http.server 8000
     ```
   * Using Node/NPM:
     ```bash
     npx http-server -p 8000
     ```
3. Open your browser and navigate to **`http://localhost:8000`**.
